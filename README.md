# Dixie Plumbing Services — Emergency Plumbing (Long Beach, MS)

Mobile-first, single-page site built to out-convert directory listings (Angi / BBB / Yellow Pages / Facebook). The whole page is optimized for one action: **get a panicked visitor on the phone in under 3 seconds.**

## Stack

- Next.js 14 (App Router)
- Tailwind CSS
- Deployed on Vercel
- Lead storage: Supabase (`service_requests` table)

## Conversion features

| Feature | Where |
| --- | --- |
| Sticky call button, always on screen | `app/page.jsx` (bottom of file) — `tel:` link, safe-area aware |
| Above-the-fold call CTA (name, value prop, hours badge, phone, single CTA) | Hero section |
| Secondary CTA: 4-field request form with urgency | `components/RequestForm.jsx` |
| Trust bar (licensed/insured, 10+ yrs, 5.0★/50+ reviews, guarantee) | Directly under hero |
| Emergency "shut off the main, then call" band | Red band under trust bar |
| Service area + ZIP codes | `lib/site-data.js` → `CITIES` |
| Real testimonials | `lib/site-data.js` → `TESTIMONIALS` |
| FAQ answering price, response time, real hours, estimates | `lib/site-data.js` → `FAQS` |
| LocalBusiness + FAQPage schema.org JSON-LD | `app/layout.jsx` |
| Local SEO meta title/description | `app/layout.jsx` |

## Speed

No images, no carousels, no autoplay video, no web fonts — every icon is inline SVG, so the page is a single lightweight HTML document with one CSS file.

## Local development

```bash
npm install

```

## Required environment variables (Vercel → Project → Settings → Environment Variables)

| Variable | Notes |
| --- | --- |
| `SUPABASE_URL` (or `NEXT_PUBLIC_SUPABASE_URL`) | Supabase project URL |
| `SUPABASE_SERVICE_ROLE_KEY` (or `SUPABASE_ANON_KEY`) | Server-side only. Prefer the service role key — RLS is enabled with no public policies, so leads can't be read by the anon key. |

Without these, `/api/request-service` returns 503 and the form automatically falls back to a tap-to-call button, so no lead is ever silently dropped.

## Leads table

```sql
create table public.service_requests (
  id bigint generated by default as identity primary key,
  created_at timestamptz not null default now(),
  name text not null,
  phone text not null,
  service text,
  urgency text,
  city text,
  details text,
  source text default 'website',
  user_agent text
);
```

Query new leads in the Supabase SQL editor:

```sql
select created_at, name, phone, service, urgency, city, details
from public.service_requests
order by created_at desc;
```
